📋 Instructions & Requirements

✅ Required Columns

  • Registration Number - Must be unique (duplicates will be skipped)
  • First Name - Student's first name
  • Middle Name - Student's middle name
  • Last Name - Student's last name
  • Gender - Male/Female/Other
  • Date of Birth - Format: YYYY-MM-DD (e.g., 2005-01-15)
  • Class - Form 1, Form 2, Form 3, Form 4, Form 5, Form 6
  • Section - Class section (A, B, C, etc.)
  • Parent Name - Parent or guardian full name
  • Parent Phone - Parent contact number

📝 Optional Fields

  • Date of Admission - When student joined the school
  • Region - Student's home region
  • District - Student's home district
  • Ward - Student's home ward
  • Village - Student's home village
  • Division - Academic division
  • Tribe - Student's tribe/ethnicity
  • Last School Attended - Previous school
  • Parent Phone 2 - Alternative parent contact
  • Nearby Person Phone - Emergency contact
  • Health Status - Any health conditions
  • School Status - Active/Graduated/Transferred
💡 Pro Tips:
  • Download the template below for the correct format
  • First row must contain column headers exactly as shown above
  • Registration numbers must be unique - duplicates will be automatically skipped
  • Keep date format consistent throughout the file
  • Maximum file size: 10MB
