Required Format

The file must be .xlsx. Row 1 must contain headers. Rows with missing required values are skipped, not guessed.

Required Columns

  • Registration Number
  • First Name
  • Gender
  • Date of Birth
  • Class
  • Section
  • Date of Admission
  • Region
  • District
  • Ward
  • Village
  • Parent Name
  • Parent Phone

Optional Columns

Middle Name, Last Name, Division, Tribe, Last School Attended, Parent Phone 2, Nearby Person Phone, Health Status, School Status.

O-Level sections must be A-F. A-Level sections must be combinations like PCB, PCM, EGM, HGK, HGL.
